# News Podcast

RSSから選んだニュースを、出典付きの短い音声番組としていつでも聴けるアプリです。

</p>

## できること

- 購読中のRSSをもとに、ニュース番組の生成を依頼できます。
- 生成中の状況を確認し、完成した番組を音声で再生できます。
- 各番組で元記事の出典を確認できます。
- 購読するフィードと日次の生成時刻を管理できます。
